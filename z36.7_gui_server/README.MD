Финальное задание Skillfactory 36.7

Реализован GUI система управления для серверной части приложения. 
В приложении два дампа базы данных для postgresql  и Mysql. 
В папках build находятся файл config.ini где необходимо прописать данные базы, той которую вы выбирите.
В папке gui_client - находится учебная программа предложенная в программе обучения. - она не видоизменялась и не дополнялась!
